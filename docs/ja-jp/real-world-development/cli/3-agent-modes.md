最初は小さな機能を追加しました。より大きな変更には、さらにしっかりしたプロセスが必要です。GitHub Copilot CLI は、組織で使われている既存のワークフローに沿って開発を進められます。このレッスンから、典型的なエージェント主導の開発プロセスをいくつかのレッスンにわたって実践します。まず issue を使って機能を作成し、コードが正しいこと、機能が期待どおりに動作することを確かめ、最終的にプロジェクトにマージします。

> [!NOTE]
> 機能開発を進める間は、同じ会話とブランチを使います。通常は作業するファイルの種類ごとに異なるブランチや PR を使いますが、ここでは主な概念に集中できるよう、手順を簡略化しています。

このレッスンでは、次の内容を学習します。

- GitHub issue から新しい Copilot の会話を始めます。
- Plan モードで要件を決めます。
- Autopilot モードで機能を実装します。
- コードをレビューします。
- 転送されたブラウザーで機能を手動で検証します。

この機能の作業を続けながら、リポジトリの指示を更新し、既存の `quality-checks` スキルをカスタマイズし、MCP による検証を追加して QA エージェントを作成し、機能の PR を作成します。

## シナリオ

Tailspin Toys のカタログは拡大しており、利用者はカテゴリーや発行元でゲームを絞り込む必要があります。バックログの issue には機能が説明されていますが、複数カテゴリーを組み合わせる方法など、実装前に合意が必要な詳細もあります。Plan モードで要件を明確にしてから、範囲を定めた実装を Autopilot に許可します。

## 背景

AI コーディング エージェントを開発ワークフローに導入しても、基本的な工程は変わりません。むしろ、より重要になります。多くの開発者は、次のような流れで作業します。

1. 実装する作業を説明した issue から始めます。
2. 実装する内容を計画します。
3. コードを作成してレビューします。
4. テストを実行し、コードを検証します。
5. 新しい機能を手動で検証します。
6. プル リクエスト (PR) を作成します。
7. コードレビューが完了し、継続的インテグレーションが成功したら、コードをマージします。

> [!NOTE]
> チームや組織によって詳細は異なりますが、多くの場合はここに示した流れを基本にしています。

この標準的な進め方に従うことで、AI が生成したコードが要件を満たし、手作業で書いたコードと同じレビューと検証を受けるようにできます。

## 会話モード

**会話モード**は、エージェントにどの程度の自律性を与えるかを決めます。<kbd>Shift</kbd>+<kbd>Tab</kbd> を押すと、モードを切り替えられます。

- **Interactive**: 開発者とエージェントが協力して作業します。エージェントは変更を提案し、次の操作に進む前に入力を待ちます。
- **Plan**: エージェントは最初に計画を作成し、プロジェクト ファイルを編集できません。
- **Autopilot**: エージェントは自律的にコードを書き、テストを実行し、タスクが完了したと判断するまで反復します。

まず Plan モードで計画を作成してレビューし、その後 Autopilot モードで実装します。

## issue から始める

フィルター機能の作業を始める前に、Codespace に戻り、リポジトリとターミナルを準備します。

1. Codespace に戻ります。停止している場合は、再起動してから続けます。
2. 星評価の PR がマージ済みであることを確認します。
3. ターミナルが開いていない場合は、<kbd>Control</kbd>+<kbd>\`</kbd> (Mac) または <kbd>Ctrl</kbd>+<kbd>\`</kbd> (Windows/Linux) を押します。
4. `main` を更新してから、フィルター機能用のブランチを作成します。

   ```bash
   git checkout main
   git pull --ff-only
   git checkout -b game-filters-cli
   ```

5. Copilot CLI を起動します。

   ```bash
   copilot --yolo
   ```

6. <kbd>Tab</kbd> を 2 回押して **Issues** タブを開きます。
7. <kbd>A</kbd> を押して、すべての issue を表示します。
8. 矢印キーを使い、**Allow users to filter games by category and publisher** というタイトルの issue を選択します。
9. <kbd>C</kbd> を押して issue をプロンプトに追加し、**Session** タブに戻ります。

プロンプトの先頭に `#7`（または同様の番号）が追加されていることを確認します。`#` を使うと、GitHub 上の issue やプル リクエスト (PR) をコンテキストに追加できます。

## フィルター機能を計画する

計画を立てると、機能の実装方法やタスクの進め方を Copilot に任せる前に決められます。複雑な作業では、時間をかけて計画を立てるのが有効です。Plan モードに切り替え、Copilot に計画を作成してもらいます。

1. <kbd>Shift</kbd>+<kbd>Tab</kbd> を押して Plan モードに切り替えます。プロンプトの下にあるモード表示が **Plan** であることを確認します。
2. 直前の手順で追加した issue の後に、次のプロンプトを入力します。

   ```plaintext
   Create a plan for implementing this feature.
   ```

Copilot はプロジェクトを調べ、最適な方法を検討して計画を作成します。

3. フィルター機能の動作について質問された場合は、希望に合わせて回答します。ここでは、選択肢に正解や不正解はありません。
4. 計画が完成したら、<kbd>Control</kbd>+<kbd>E</kbd> (Mac) または <kbd>Ctrl</kbd>+<kbd>E</kbd> (Windows/Linux) を押して、計画を展開します。
5. 計画を上下にスクロールしてレビューします。
6. 決めた内容と異なる部分があれば、Copilot に計画の修正を依頼します。

## Autopilot を承認する

計画を作成してレビューしたら、実装に進みます。Autopilot を使うと、Copilot にタスクの反復作業を任せられます。

1. **Accept plan and build on autopilot (recommended)**、またはインストール済みのバージョンで同様の名前が付いたオプションを選択します。
2. プロンプトの下にあるモード表示が **Autopilot** であることを確認します。
3. Copilot が計画に沿って反復し、コードを生成してテストを実行する様子を確認します。

> [!NOTE]
> 承認すると、すぐに実装が始まる場合があります。先に計画をレビューしてください。Copilot が依存関係の不足やポートの競合を報告した場合は、チェック完了と見なす前にセットアップの問題を解決します。

## 実装をレビューして検証する

コードの生成後、ほかのコードと同じようにマージ前にレビューします。コードを確認し、サイトを起動して問題なく動作するか検証します。

1. <kbd>Shift</kbd>+<kbd>Tab</kbd> を押して Interactive モードに切り替えます。モード表示が **Plan** でも **Autopilot** でもないことを確認します。
2. `/diff` を入力し、フィルター機能の実装とテストを調べます。
3. 結果を issue と計画時に決めた内容に照らして確認します。
4. コードのレビューが終わったら、<kbd>Esc</kbd> を押して差分画面を閉じます。
5. プロジェクトのチェック結果を確認し、失敗があれば Copilot に解決を依頼します。

## 新機能を試す

コードに問題がないように見えても、実際に動くことを確認する必要があります。前と同じように Copilot にアプリケーションを起動させ、Codespaces で転送されたポートからサイトを開きます。

1. Copilot にアプリケーションの起動を依頼します。

   ```plaintext
   Start the app so I can try the filtering feature in my browser. Tell me the URL and leave the server running.
   ```

2. Codespaces でポート `4321` が利用可能になったら **Open in Browser** を選択します。
3. カテゴリー、発行元、計画で合意した組み合わせを使って絞り込みます。
4. リセット時と結果がない場合の動作が、issue と合意内容に一致することを確認します。
5. Codespace に戻り、Copilot に起動した開発サーバーを停止するよう依頼します。
